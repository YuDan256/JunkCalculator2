## 1. 问题：合成时的分支穿越

`cas.integ` 曾返回**符号相反**的原函数（已由 `aebe284` 的两道防线消除"给错答案"，
但根因未除）。链条如下（全部实测，`p = sym("p")`）：

```
cas.integ(p^2/sqrt(1-p^2), p)
  → Radical Substitution，u = sqrt(1-p^2)
  → 内层被积函数 -i*sqrt(p^2-1)，命中表项（表项本身正确）
  → 回代：纯语法 subs(u -> sqrt(1-p^2))
       sqrt(u^2-1) 里的 u^2-1 化简成 -p^2，再经 trySquareRoot
       拆成 sqrt(-1)*sqrt(p^2) → i*p
  → log 项因此落到另一支，整个结果取反
```

**关键观察：各部件在各自的分支上都正确。** 内层表项经 `cas.verifyInteg` 在复数测试点上
通过；`sqrt(-p^2) = i*p` 对 `p > 0` 也是主分支的正确取值。错的是**合成**：正变换与回代
各自选了使局部成立的分支，合成后整体跨了分支，于是合成结果不等于值的合成。

因此靠"修某一条规则"治不了；要让重写规则**携带并检查前提条件**。

**当前的两道临时防线**（`aebe284`）只能**拒绝**，不能**给对**：
1. 策略循环自检 → 跳过可疑候选，让后续策略接手（救回 3/4）
2. `cas.integ` 出口自检 → 仍不可信则抛 `CalculusError`（第 4 例）

对 35 个积分的扫描：临时防线前「31 正确 / 4 错答案」，之后「34 正确 / 1 拒绝 / 0 错答案」。

## 2. 被否掉的 S1（记录理由，勿再提）

**S1：自检失败时先试"反号候选"再拒绝。**

- 依据：实测本类缺陷 **4/4 都是整体符号取反**；并且实验证实
  `p^2*sqrt(1-p^2)` 那例的反号候选数值上正是正确原函数
  （`F'(0.5) = +0.216506`，原候选为 `-0.216506`）。
- 代价极小，且仍不会给错答案。
- **被否理由（作者 2026-09-22 决定跳过）**：它是**启发式**，只覆盖"整体 ±1"型的分支错误。
  分支错误未必表现为整体取反（例如和式里只有一项翻号），那时反号也过不了自检、仍会拒绝。
  既然要做就做真正的分支感知，不要先塞一个只对观察到的几例有效的补丁。

## 3. 核心约束：假设不能挂在节点上

| 事实 | 位置 |
|---|---|
| `SymVar` 只有一个 `std::string name`，没有任何前提/假设字段 | `Symbolic.h:291` |
| 节点在全局 intern 池里按 `hashValue + equals` 去重，同名变量全局**只有一个节点** | `Symbolic.cpp:212`（`SymPool::intern`）、`Symbolic.cpp:237`（`SymExpr::intern`） |
| `SymNum` 的 `hashValue` 由数值哈希决定，节点身份按表示严格区分 | `Symbolic.cpp:773` |

**推论**：若把假设挂在 `SymVar` 节点上，`assume(p>0)` 之后所有 `p` 都变成带假设的节点，
与池中已有的 `p` 不再是同一个 —— 要么让池按假设区分（intern 语义整体改变，
`equals`/`hashValue` 全线受影响），要么干脆不 intern 变量（`SymExpr::operator==`
的指针快路径失效，性能与去重都退化）。

⇒ **假设必须放在独立的"假设环境"里，按变量名查，随调用链传递**，节点模型不动。

## 5. 需加守卫的重写清单

### 5.1 真危险：断言了前提，无前提时不应重写

| 位置 | 重写 | 前提 | 无前提时（D3=a） |
|---|---|---|---|
| `Symbolic.cpp:5280` | `sqrt(z^(2k)) → z^k` | `z ≥ 0`（或已知 `z` 为偶次幂/正数） | 保留 `sqrt(z^2k)` 不化简 |
| `Symbolic.cpp:5287` | `sqrt(a*b) → sqrt(a)*sqrt(b)` | `a ≥ 0` 且 `b ≥ 0` | 不拆分 |
| 待查 | `log(exp(z)) → z` | `|Im z| < π` | **需确认此规则是否存在及其位置** |

> `sqrt(-1) → i` 属"**选定主分支**"而非"断言前提"，与 `exp(c*log a) → a^c`
> （`Symbolic.cpp:4307`，主分支幂的定义）同类。这类不需要前提守卫，但**必须与
> 守卫后的规则保持一致** —— 现状正是这两类混用才产生穿越。

### 5.2 无害（已核对，不需要守卫）

| 位置 | 重写 | 为什么无害 |
|---|---|---|
| `Symbolic.cpp:4289` | `exp(log a) → a` | 主分支下恒等（`a ≠ 0`） |
| `Symbolic.cpp:4307` | `exp(c·log a) → a^c` | 这就是主分支幂的定义 |
| `Symbolic.cpp:5238` | 负数无实平方根 → 放弃 | 保守方向，安全 |

`log` 另有若干处（`3840` / `3852` / `4249` / `4299`）只是**识别** `log` 节点
（用于分部积分、反函数消去），不产生重写，无需守卫。

## 6. 传播机制

假设环境要穿过这些路径，否则等于没做：

| 路径 | 要求 |
|---|---|
| `subs(expr, var, val)` | 代入后**丢弃**被代变量上的假设；对代入值能推出的新前提并入环境 |
| `simplify` / `simplifyCore` | 只读环境，不修改；重写规则查环境决定是否触发 |
| `integrate` | 进入换元时把换元关系（如 `u = sqrt(1-p^2)` ⇒ `u ≥ 0`）**加入**环境；回代时据此选分支，而非让 `trySquareRoot` 猜 |
| `diff` | 透传 |
| `solve` / 其它推导入口 | 透传 |

**对本案的最小充分条件**：只要回代时环境里有 `u ≥ 0`（换元定义域）与"`u^2 - 1` 的符号未知"，
`trySquareRoot` 就不会把 `sqrt(u^2-1)` 化成 `i*p`，穿越即不发生。

## 7. 语料影响预估（**需实测，本文不给数字**）

D3 选"保守"会让**无前提**下的化简结果变多（保留 `sqrt(p^2)` / 不拆 `sqrt(ab)`），
因此 109 例 CAS 语料**预期会有变化**，且方向是"更少化简"。

测量方法（实施时照做，不靠估）：

1. 记录改动前 `after_full.txt` 基线（已有）
2. 实现后跑语料，逐行 diff，把**每一处变化**分类为
   「语义等价但形式不同」/「语义不等价（真回归）」
3. 对每一处"形式不同"用数值点抽查确认等值
4. 若回归条数过多，说明 D3 需要从"全局保守"改成"仅在换元回代等**跨界点**保守"

## 9. 风险与代价（诚实评估）

- **不是"改两条规则"**：要新增一层贯穿 `simplify` / `subs` / `integrate` / `diff` 的
  环境参数，触及 CAS 主要入口的签名。
- **语料预期变化**：保守化会让部分现在化简的结果退化成未化简形式。这是"宁少化简、
  不错化简"的取舍，需作者认可。
- **API 是新增概念**：CAS 现在没有任何"假设/条件"概念，用户侧要新增语法或函数。
- **节点 intern 不能动**：动了会牵连 `equals` / `hashValue` / 指针快路径，风险远大于收益。
- **不能承诺"完全消除分支问题"**：本方案消除的是**已知重写规则**的分支穿越；
  `√`/`log` 的多值性在数学上无法通过保守重写完全消除，只能保证"不让重写偷偷改变分支"。
