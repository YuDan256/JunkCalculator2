# Junk Calculator 2 (v2.4.x) 维护策略

本文档说明了 JC2 v2.4.x 分支（基于栈的虚拟机最终版本）的长期支持与维护规则。

## 1. 版本状态
当前分支 (`release/2.4.x`) 已进入 LTS（长期支持）状态，代码处于特性冻结（Feature Frozen）阶段。为了保障现有架构的稳定性，并为下一代基于寄存器的 v2.5 版本开发集中资源，本分支将实行严格的修改限制。

## 2. 问题处理原则

### 2.1 接受修复的缺陷 (Critical Bugs)
本分支仅接受可能导致引擎核心崩溃或逻辑严重错误的缺陷修复。包括但不限于：
* **内存安全问题**：内存泄漏、悬空指针、或 GC 导致的异常。
* **系统级崩溃**：虚拟机或原生模块触发的宿主进程 Crash。
* **核心计算错误**：CAS 代数推导错误、大整数底层计算错误等影响结果正确性的 Bug。

针对此类问题，修复后将发布 `v2.4.5.x` 补丁版本。

### 2.2 不予修复的瑕疵 (WONTFIX)
以下非致命问题将不在本分支中投入精力修复，统一推迟至 v2.5 版本解决：
* 不影响程序正常运行的轻微性能损耗。
* 边缘语法或特定边界条件下的报错行号偏移。

### 2.3 拒绝的新特性 (Feature Requests)
本分支停止接纳任何新特性请求。以下内容将被直接拒绝：
* 新增标准库函数、原生模块扩展或 API。
* 新增语法糖、词法解析规则或编译器特性。

## 3. 分支与提交指南
* **缺陷修复 (Bugfix PR)**：如提交针对上述严重缺陷的修复，请务必将 PR 的目标分支设置为 `release/2.4.x`。
* **新特性开发**：所有的架构重构（包括寄存器虚拟机、IR 中端等）与新特性开发均已转移至 `master` 及对应 feature 分支。请勿将新特性提交至本维护分支。
